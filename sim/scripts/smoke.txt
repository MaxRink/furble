# Exercise initial-menu navigation, the fake FauxNY scan page, the connection
# flow, and the shutter page through deterministic UI actions. `action nav scan`
# proves navigation to the scan page; it is not discovery, pairing, or radio
# hardware proof.
seed fauxny true
seed saved_camera true
wait 500
home
wait 300
assert ui.page main
capture main
action nav scan
wait 700
assert ui.page scan
capture scan
home
wait 300
action connect
wait 1800
assert-eventually-virtual 60000 ui.connected yes
assert ui.page connected
capture connected
action blind
wait 500
assert ui.page shutter
capture shutter
exit
