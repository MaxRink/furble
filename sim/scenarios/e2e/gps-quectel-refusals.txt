# A Quectel part that does not implement everything the driver can send, and
# the one standby interval it cannot do. Each refusal is reported, never hidden:
# the receiver answers $PAIR001,<id>,3 and the driver records a nack.
#
# LC76G (PA) and (PB) do not support PAIR050 (Q76 2.3.9 note 2, page 38), so the
# fix rate stays at the receiver's 1 Hz. The 5 s duty interval is below PAIR650's
# 10 s minimum (Q76 2.3.46 page 69), so no backup command goes out at all and
# the receiver keeps printing. Plan 367.
seed gps true
seed gps_model quectel
seed gps_quectel_no_fix_rate true
seed gps_gnss 1
seed gps_rate 2
seed gps_power 1
seed gps_duty 5
wait 8000
assert gps.backend quectel

# The plan is the fix rate, SBAS and the search mode. The rate command comes
# back refused.
assert-eventually 5000 gps.config.0.state NACKED
assert_min text.naks 1
assert text.rate_ms 1000

# A refused command does not stop the rest of the plan.
assert-eventually 5000 gps.config.2.state ACKED

# The refused rate left the receiver at its own 1 Hz, and 5 s is not a
# documented backup interval, so nothing was sent and the receiver is still
# awake and fixing.
assert text.backups 0
assert text.standby_s 0
assert text.sleeping 0
assert-eventually 5000 gps.source uart
wait 6000
assert_min gps.fresh_fixes_parsed 2
exit
