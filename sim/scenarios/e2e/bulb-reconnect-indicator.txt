# task #54: the full-screen Bulb page must surface a mid-session drop too.
#
# PR #154 added a reconnect banner to the Remote shutter page, but the equally
# full-screen Bulb page, the other place shots are taken, still showed nothing
# when a live link dropped: the drop was only carried by the small shared status
# icon. A drop must now show a red Bluetooth icon plus "Reconnecting" text
# overlaid on the Bulb page, non-blocking, and clear it on recovery. Connect the
# FauxNY camera with reconnect on, navigate to the Bulb page, drop the link, and
# confirm the banner tracks the state and the page never changes under it.
seed fauxny true
seed reconnect true
wait 300
action connect
wait 3000
assert-eventually-virtual 3000 control.state active
assert-eventually-virtual 2000 ui.connected yes
# Navigate to the full-screen Bulb page by clicking its real menu button.
action nav bulb
wait 200
assert ui.page bulb
# Connected: no banner on the Bulb page.
assert ui.bulb_reconnecting no
assert ui.bulb_status hidden
# Drop the active link. The liveness poll must show the banner without leaving
# the Bulb page.
action drop
wait 700
assert control.state connecting
assert ui.page bulb
assert ui.bulb_reconnecting yes
# One camera down: on a panel wide enough (the 135 px default here) the banner
# names the dropped camera, "Reconnecting FauxNY Camera". bulb_named checks the
# banner text against the board's width policy, so it also holds on the 80 px
# StickC, where the name is omitted and the icon shows alone. The Bulb banner
# shares the shutter banner's helper, so it inherits the same naming.
assert ui.bulb_named yes
# Reconnect completes and the banner clears, still on the Bulb page.
wait 2500
assert control.state active
assert ui.page bulb
assert ui.bulb_reconnecting no
assert ui.bulb_status hidden
exit
