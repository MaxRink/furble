# The Infrared, Feedback and Storage submenus are gated on an IR LED, a feedback
# output and an SD card. The simulator reports these present through the
# FURBLE_SIM_IR / FURBLE_SIM_FEEDBACK / FURBLE_SIM_SD capability env vars, which
# run-e2e.sh sets for the whole suite. With them present, each submenu entry
# exists in the settings menu and navigating to it leaves the settings page. If
# the capability were absent the nav would be a no-op and the page would stay on
# settings, so these asserts also prove the gating is wired.
wait 400
home
wait 200
action nav settings
wait 200
assert ui.page settings

action nav infrared
wait 200
assert ui.page other

home
wait 150
action nav settings
wait 150
action nav feedback
wait 200
assert ui.page other

home
wait 150
action nav settings
wait 150
action nav storage
wait 200
assert ui.page other

exit
