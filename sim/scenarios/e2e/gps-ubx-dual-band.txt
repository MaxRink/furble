# A virtual NEO-F10N: the dual-band F10 firmware. MON-VER names protocol 40.00
# and the module, the capability probe asks for the four L5 signal keys at the
# default layer and gets them, and the plan then writes both bands of each
# enabled constellation.
#
# Key ids: GPS L5 0x10310004, Galileo E5a 0x10310009, BeiDou B2a 0x10310028 and
# QZSS L5 0x10310017 (u-blox F10 SPG 6.00 interface description UBX-23002975
# R02, 4.9.20 pages 158 and 159, Table 46). The bands of one constellation
# cannot be enabled apart (NEO-F10N integration manual UBXDOC-963802114-12193
# R04, 2.1.3 page 10).
seed gps true
seed gps_model f10
seed gps_m10_hot true
# GPS and Galileo only, so BeiDou and QZSS stay at the receiver preset and the
# L5 rows of the two enabled constellations are the interesting ones.
seed gps_gnss 9
wait 8000
assert gps.backend ubx
assert gps.ubx.module NEO-F10N
assert gps.ubx.firmware SPG_6.00
assert gps.ubx.family 2
assert gps.ubx.bands 3
assert gps.ubx.band_probed 1
assert gps.ubx.psm_supported 0
assert m10.monver_polls 1
assert-eventually 3000 gps.ubx.verified 1
# The probe was answered, not refused: no NAK on this receiver at all.
assert m10.naks 0
assert gps.ubx.l5_written 1
assert gps.ubx.l5_refused 0
assert m10.ram.1031001f 1
assert m10.ram.10310001 1
assert m10.ram.10310004 1
assert m10.ram.10310021 1
assert m10.ram.10310007 1
assert m10.ram.10310009 1
# QZSS follows GPS, both bands with it.
assert m10.ram.10310024 1
assert m10.ram.10310012 1
assert m10.ram.10310017 1
assert m10.ram.10310020 1
# BeiDou was not decided, so its keys are deleted from BBR and B1I is never
# written on a dual-band part (NEO-F10N data sheet UBX-23002117 R05, Table 4
# page 5).
assert gps.ubx.gnss 9
# No CFG-PM group on this firmware: power save stays off and no PM key is sent,
# which is why the receiver does not NAK the power batch (F10 interface
# description 4.9; module manual, appendix migration table, page 64).
assert gps.ubx.psm 0
assert-eventually 5000 gps.source uart
assert gps.from_pvt 1
assert gps.ubx.fix_type 3
exit
