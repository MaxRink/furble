# Pairing a camera that is already saved must be refused, not started, and the
# refusal must be dismissable.
#
# NOT CERTIFIED. Read this before trying to re-enable it.
#
# The refusal lives in UI::beginPairing(), which is reached only by activating a
# scan result row. Before PR #261 the row came from the FauxNY setting and was
# created inside startScan(), so it held the focus when the page loaded and a
# bare "action select" activated it deterministically. With the production
# CameraList the FauxNY row and the seeded saved camera are two different
# cameras, so the refusal never fires; the row has to come from the virtual
# radio instead, and a radio row is materialized after the page has already
# focused its back button.
#
# Moving the focus onto it is what cannot be made deterministic today. "key
# down" drives GPIO 38 for 80 virtual ms and the UI samples the button on its
# own cadence, so on a page that is busy draining scan results the press is
# missed roughly half the time; measured 3 of 6, 4 of 8 and 5 of 8 across
# variants. Repeating the press makes it worse, not better, because a press that
# does land walks the focus off the row again. "btn a" and "btn b" do not move
# the focus on this page in either layout.
#
# What covers this today: camera-list-protocol pins the identity rule itself
# with teeth, and stale-bond-pairing-lost.txt plus connect-fail-progress.txt
# cover UI::showConnectError() and closeConnectErrorDialog() end to end on all
# three panels in both input layouts. What is missing is only the UI-level proof
# that the Scan row refuses.
#
# To re-enable: give the scenario DSL a deterministic way to activate a scan
# result (an "action scan-row N" that dispatches the row's click handler the way
# "action nav" dispatches a menu button), then drop the key presses below and
# set certified true in the manifest.
seed fauxny false
seed ble_peers fuji
seed ble_saved true
wait 400

home
wait 200
assert ui.page main
assert ui.connect_error none

# The saved camera turns up in the scan results.
action nav scan
wait 500
assert ui.page scan
assert-eventually 2000 camera.count 1
wait 300

# Tapping its row must refuse instead of connecting.
key down
wait 200
action select
wait 300
assert ui.connect_error already_saved
assert ui.modal_count 1
assert control.state idle
assert control.targets 0

# And the box has to go away again. Its OK button joins the input group and
# takes the focus, so this activation needs no navigation and is reliable.
action select
wait 300
assert ui.connect_error none
assert ui.modal_count 0
assert control.state idle
assert control.targets 0

exit
