# Regression guard for the menu focus outline dedup. A focused menu row must
# draw no focus ring at all: the LVGL default theme already fills a focused
# lv_menu_cont with the primary accent colour, so the accent fill is the single
# focus cue. Menu rows set LV_OBJ_FLAG_STATE_TRICKLE, so the focused row
# propagates LV_STATE_FOCUSED to its child icon and label. A regression that
# attaches the outline style to the row or its children makes this count climb.
seed fauxny true
wait 300
# The home menu boots with Scan focused; it carries an icon and a label. The
# accent fill highlights it, so no outline may be drawn.
assert ui.focus_outline_count 0
action nav settings
wait 400
# The settings menu first row (Display) is focused; it also has an icon and a
# label, the exact shape that once produced a triple outline.
assert ui.focus_outline_count 0
# The Remote page shutter lock is the only focusable control on that page, so it
# must not draw a focus ring at all. Open the Remote page, focus the lock, and
# confirm its outline width is zero.
action blind
wait 300
action focus-lock
wait 100
assert ui.lock_outline 0
exit
