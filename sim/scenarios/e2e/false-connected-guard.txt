# End-to-end mirror of the stale-connected hardware bug at the UI layer. A camera
# that never establishes a link must not present as connected. The connect_fail
# seed registers one virtual Fujifilm peer and makes NimBLEClient::connect() fail
# at the transport, so this drives the real connect-failure path: FauxNY has no
# radio and cannot fail. Confirm the UI never shows the connected page and
# Control never reports an active link.
seed connect_fail true
wait 300
action connect
assert-eventually-virtual 10000 control.state idle
assert control.connected 0
assert ui.connected no
assert ui.liveness_violations 0
exit
