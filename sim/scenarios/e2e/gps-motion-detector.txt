# Phase 1 GPS motion state machine over IMU::MotionSource (plans/18, plans/20).
#
# The detector itself now lives in PR20's MotionSource: the same 60 s
# continuous-quiet hold and immediate exit this PR used to implement in its own
# 10 Hz variance window, shared by all three backends. This PR consumes the
# verdict and adds the setting, the gate and the receiver policy hook. So the
# first thing the scenario pins is that the source really armed, because an
# unarmed source reports MOVING forever and a gate that reads it would look
# identical to a device that is genuinely moving.
#
# The second half is the phase 1 contract: the detector is advisory and must not
# move the receiver. Nothing consumes isStationary() yet, so the receiver state,
# the degraded flag, the UART write count and the wake lock all have to read the
# same on both sides of a state transition. The exit transition is bracketed
# inside a short window so the pinned lock count cannot drift for an unrelated
# reason. The wake lock is asserted as a held count rather than an acquire
# tally: the tally is board dependent (the 80x160 model never acquires it at
# all) while "the detector took no lock" is the invariant every board holds.
#
# Mutations that kill these assertions are recorded in plans/18-gps-motion.md.
seed gps true
seed imu true
seed gps_motion true
seed gps_power 0
seed gps_duty 0
seed gps_uart_mode ack
wait 400

# The source armed, on the software backend the modelled board defaults to.
# "inactive" here would mean the gate below is reading a source that never runs.
assert ui.motion_backend software
assert ui.motion_state moving

# All three gates are on, so the GPS detector is live and starts out moving:
# the quiet window has not run yet.
assert setting.gps_motion 1
assert gps.motion_state moving
assert gps.state tracking
assert uart.count 0

# Hold the device flat and still. MotionSource is polled at 1 Hz from the UI
# housekeeping timer and needs 60 s of continuous quiet, so entry lands just
# past 61 s of held-still virtual time.
action imu.accel 0 0 1
wait 59600
assert gps.motion_state moving
wait 3400
assert ui.motion_state stationary
assert gps.motion_state stationary

# The receiver did not move while the detector did.
assert gps.state tracking
assert gps.degraded 0
assert uart.count 0
assert power.no_light_sleep 0

# Exit is immediate. 2 g is 1 g away from the 1 g rest reference, five times the
# 0.20 g threshold, so the next poll reports moving.
action imu.accel 0 0 2
wait 1500
assert ui.motion_state moving
assert gps.motion_state moving

# And the receiver still did not move. Same reads, same values, one transition
# later.
assert gps.state tracking
assert gps.degraded 0
assert uart.count 0
assert power.no_light_sleep 0
exit
