# M5Stack Core IP5306 profile.
#
# The IP5306 has a four-level gauge, no current ADC, a 64 s low-load boost
# cutoff and no PM1 watchdog. The board has no PSRAM. The cutoff timer itself is
# not modelled: the simulator has no continuous-load accounting and no PMIC
# power-cut event, so only the profile fields below are asserted. M5Unified
# writes SYS_CTL2 bits 3:2 = 11, which is 64 s, not the 32 s power-on default.
# See plans/334-sim-hardware-alignment.md.
seed hw_profile core
wait 100

assert hw.profile core
assert hw.mcu esp32
assert hw.flash_kb 4096
assert hw.psram absent
assert hw.pmic ip5306
assert hw.gauge four_level
assert hw.touch no
assert hw.display 320x240
assert hw.sd yes
assert hw.audio yes
assert pmic.battery present
assert pmic.power_latch latched
assert pmic.watchdog unavailable
assert platform.battery.current -1

assert mem.internal_total 532480
assert mem.psram_total 0
assert mem.component.main_stack 16384
assert mem.component.lvgl_draw 20480
assert hw.usb uart
assert hw.wifi yes
assert hw.ethernet no
assert hw.ble yes
assert hw.ir yes
# The Core has no calendar RTC chip (docs/console-commands.md).
assert hw.rtc no
assert hw.rtc_capability match
assert hw.gauge four_level
exit
