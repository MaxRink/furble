# UI polish: the header battery indicator must stay anchored to the status
# row's top-right corner and never reflow when sibling status icons appear or
# disappear.
#
# Before this fix the battery block packed inline with the other status icons,
# so it shifted left or right as the GPS icon and the mid-session reconnecting
# Bluetooth symbol showed and hid. A zero-width flex-grow spacer now pins the
# battery block to the header's right edge. Enable GPS (so its icon occupies the
# row) and drive a connect, a mid-session drop (which shows the reconnecting
# Bluetooth symbol), and a recovery, asserting the battery stays pinned right the
# whole time. battery_pinned is board independent, so this holds on every panel.
seed fauxny true
seed reconnect true
seed gps true
wait 300
action connect
wait 3000
assert-eventually-virtual 3000 control.state active
assert-eventually-virtual 2000 ui.connected yes
# Connected, GPS icon present: the battery sits flush at the right edge.
assert ui.battery_pinned yes
# Drop the active link: the reconnecting Bluetooth symbol appears in the status
# row. The battery must not move to make room for it.
action drop
wait 700
assert control.state connecting
# Drop-surfacing indicators are recorded, not enforced, until the connect timer
# race is fixed in production. doConnect() readies and resumes the connect timer
# while Control::connectAll() has only queued CMD_CONNECT, so if the timer's
# first tick beats the control task out of STATE_IDLE the handler pauses the
# timer and no later drop is ever surfaced. On device the priority 4 control
# task preempts the LVGL task on the queue send and the window never opens; the
# simulator's UI task is not priority gated, so a loaded host loses the race.
# See residual gap 4 in plans/161-sim-real-control.md. The timer-independent
# state (control.state, control.connected, ui.connected, ui.reconnect_count)
# stays hard asserted below.
xassert ui.reconnecting yes
assert ui.battery_pinned yes
# Reconnect completes and the Bluetooth symbol hides again. The battery is still
# pinned to the same right edge, having never shifted.
wait 2500
assert control.state active
assert ui.reconnecting no
assert ui.battery_pinned yes
exit
