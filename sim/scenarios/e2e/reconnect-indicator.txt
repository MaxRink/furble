# F3 / task #54: a mid-session BLE link drop must update the UI.
#
# The connect timer used to park on STATE_ACTIVE and only re-arm on a fresh
# connect, so a drop after a good connect was never observed: the screen kept
# showing connected while control dropped and retried. Connect the FauxNY camera
# with reconnect on, drop the link, and confirm the reconnecting box reappears,
# then confirm the connected view returns once the link is back.
seed fauxny true
seed reconnect true
wait 300
action connect
wait 1000
assert control.state active
assert ui.connected yes
assert ui.connect_box hidden
# Drop the active link. The liveness poll must notice and show the box.
action drop
wait 650
assert control.state connecting
assert ui.connect_box visible
# The reconnect completes and the connected view is restored.
wait 1000
assert control.state active
assert ui.connected yes
assert ui.connect_box hidden
exit
