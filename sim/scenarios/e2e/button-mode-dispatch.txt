# One-button mode dispatch. Verify the new BUTTON_MODE routing: the default
# two-button mode fires the shutter on a main-button press. One-button mode
# maps three gestures: single press-and-hold dispatches focus, a double click
# dispatches exactly one shutter press+release, and a click-then-hold dispatches
# a single sustained shutter press+release. The double click and click-then-hold
# gestures must NOT leak a leading focus tap. The SDL sim models discrete button
# events, not LVGL's 400 ms streak-timing window, so the multi-click actions
# replay the full real event stream (first press, release, short click, second
# press) and inject the streak the dispatch classifies. Timing feel stays a
# hardware concern; this asserts the dispatch decision only, checking both the
# presence of the expected commands and the absence of the stray focus leak.
seed fauxny true
wait 300
action connect
wait 3200
assert ui.connected yes

# Default two-button mode: the main button fires the shutter, never focus.
assert camera.shutter_presses 0
assert camera.focus_presses 0
action shutter
wait 200
assert-eventually-virtual 1000 camera.shutter_presses 1
assert-eventually-virtual 1000 camera.shutter_releases 1
assert camera.focus_presses 0

# Switch to one-button mode.
action button-mode one-button
wait 100

# Gesture 1: single press-and-hold dispatches focus, no shutter.
action main-press-hold
wait 200
assert-eventually-virtual 1000 camera.focus_presses 1
assert-eventually-virtual 1000 camera.focus_releases 1
assert-eventually-virtual 1000 camera.shutter_presses 1

# Gesture 2: a double click dispatches exactly one shutter press and release.
# It must NOT leak a leading focus tap: focus_presses stays 1.
action main-double-click
wait 200
assert-eventually-virtual 1000 camera.shutter_presses 2
assert-eventually-virtual 1000 camera.shutter_releases 2
assert-eventually-virtual 1000 camera.focus_presses 1
assert-eventually-virtual 1000 camera.focus_releases 1

# Gesture 3: a click-then-hold dispatches a single sustained shutter press and
# release. It must NOT leak a leading focus tap either: focus_presses stays 1.
action main-click-hold
wait 200
assert-eventually-virtual 1000 camera.shutter_presses 3
assert-eventually-virtual 1000 camera.shutter_releases 3
assert-eventually-virtual 1000 camera.focus_presses 1
assert-eventually-virtual 1000 camera.focus_releases 1
exit
