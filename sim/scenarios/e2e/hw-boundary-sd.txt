# Linked boundary: production SD writer in src/FurbleSD.cpp and GPX writer.
#
# The real writer task, mount decision, failure counter and dated GPX path run
# against a host SD/SPI/VFS double over real POSIX file I/O. Mount, write,
# full-card failure, removed card, a settings export that has to replace the
# previous backup, an export on a full card, power-off, a hung writer that
# refuses the shutdown handshake and a writer that never takes the request are
# asserted.
#
# Runner: sh sim/scripts/run-boundary-conformance.sh
# Tests: boundary-sd-mount-write, boundary-sd-mount-fail,
#        boundary-sd-full, boundary-sd-removed, boundary-sd-export-full,
#        boundary-sd-shutdown-refused, boundary-sd-shutdown-undelivered
#
# Expected production tokens:
# sd.mount state=mounted calls=1
# sd.write path=/tmp/furble-boundary-sd/furble/20261105-120000.gpx bytes=488
# sd.card capacity_mb=32768 free_mb=30720 generation=1
# sd.power_off unmounted=1 calls=1
# sd.mount_fail state=failed calls=1
# sd.full write_failed=1 disabled=0
# sd.removed mount_failures=3 gpx_disabled=1
# sd.export_first path=/tmp/furble-boundary-sd/furble/settings.txt bytes=1575
# sd.export_replace replaced=1 bytes=1574
# sd.export_full backup_preserved=1 bytes=1574
# sd.shutdown_refused acknowledged=0 wait_ms>=8000 unmount_entered=1
# sd.shutdown_refused.released unmounted=1 track_complete=1
# sd.shutdown_undelivered acknowledged=0 queued=8 wait_ms<1000
# sd.shutdown_undelivered.released drained=1 track_complete=1
