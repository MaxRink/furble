# A sleeping panel must not receive flushed pixels.
#
# The panel is in SLPIN after the inactivity timer. A redraw still produces
# LVGL flush callbacks, and the guard must return before the RGB swap and the
# DMA push. The suppressed counter proves the callbacks happened; the code path
# returns before any pixel leaves the buffer.

seed fauxny true
seed autoconnect true
seed inactivity 1
seed display_off 2
wait 31000
action blind
action blind-shutter
wait 2000
assert_min ui.flushes_suppressed_off 1
exit
