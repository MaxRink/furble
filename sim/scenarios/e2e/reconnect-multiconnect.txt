# task #54, multi-connect: one camera dropping must not blank the trigger, and
# the status text must name how many cameras are reconnecting.
#
# With several cameras connected, a single mid-session drop must keep the
# connected/trigger view up and usable for the cameras still connected. Only the
# non-blocking status indicator reflects the retry; the connecting/progress page
# never takes over. The connected page title reads "Reconnecting (i/n)" where i
# is the number of cameras currently down and n the total in the session, so the
# text names the per-device state instead of a bare icon. Connect two FauxNY
# cameras with reconnect on, drop just one, and confirm the trigger stays on the
# connected page, one link stays live, the indicator and count reflect the
# dropped camera, and both links restore.
seed fauxny true
seed reconnect true
wait 300
action connect-two
wait 3200
assert-eventually-virtual 3000 control.state active
assert control.targets 2
assert control.connected 2
assert-eventually-virtual 2000 ui.connected yes
assert ui.connect_box hidden
assert ui.reconnecting no
assert ui.status_text Connected
assert ui.reconnect_count 0/2
# Drop only the first camera. The second stays connected, so the session and its
# trigger survive.
action drop 0
wait 700
assert control.state connecting
assert control.targets 2
# One link remains live for the trigger while the other reconnects.
assert control.connected 1
# No takeover: still on the connected page with the shutter trigger and the
# progress box hidden. The trigger view is never blanked, which is the exact
# regression the rejected page-takeover approach introduced.
assert ui.connect_box hidden
assert ui.page connected
assert ui.reconnecting yes
# The title now names the per-device state: 1 of the 2 cameras is reconnecting.
# The full string is "Reconnecting (1/2)"; the count is asserted as a single
# token here and printed for the record.
print ui.status_text
assert ui.reconnect_count 1/2
# The dropped camera reconnects and both links are live again; the count clears.
wait 2500
assert control.state active
assert control.connected 2
assert ui.connected yes
assert ui.connect_box hidden
assert ui.reconnecting no
assert ui.status_text Connected
assert ui.reconnect_count 0/2
exit
