# The four hour ephemeris validity window, bounded by the receiver own clock.
#
# furble kept clock cannot answer this. After a power cut it restores as the
# last persisted epoch plus the monotonic time since boot, with no knowledge of
# how long the board was off, so a week unplugged reads as a couple of minutes
# old. The receiver is the only clock that knows. Replay therefore arms at
# enable and commits only once the receiver has reported a UTC of its own,
# committed after the arm so a date left from the previous session cannot
# answer for this one.
#
# The fake receiver clock is moved a week forward between the capture and the
# next enable, which is what a real receiver reports after a long time
# unpowered. It keeps ticking, so the refusal is the age rule and not the
# receiver having gone quiet.
seed gps true
seed gps_baud 9600
seed gps_assist 2
seed gps_fix_date modern
seed gps_uart_mode ack
wait 300

# The GPS Data page stays open throughout, so the UI task is reading the status
# snapshot while the GPS task polls, stores and decides on its own thread. This
# scenario is the second ThreadSanitizer gate for that boundary.
action nav gps_data
wait 500
assert ui.page gps_data

# Capture a cache while the receiver reports 2026-09-06.
wait 8000
assert-eventually 8000 gps.satellites 8
wait 6000
assert_min gps.eph_cached 200
assert uart.eph_replay 0

# Move the receiver clock a long way from the capture, then re-enable. The
# cache is still on flash and still loads, and it must not be replayed.
gps-fix-date stale
action toggle gps
wait 1000
action toggle gps
wait 15000
assert_min gps.eph_cached 200
assert uart.eph_replay 0

# A receiver with RMC pruned reports a position but never a date, so the parser
# keeps whatever date the previous session left it with. A stale date must not
# be allowed to answer for this session: with no receiver time at all the cache
# age cannot be established, so after the arm deadline the cache is dropped
# rather than replayed blind. This is the true cold start case.
gps-fix-date nodate
action toggle gps
wait 1000
action toggle gps
wait 40000
assert uart.eph_replay 0

# Move the receiver clock back and let it cache again at the current date. The
# cache written during the stale leg carries the far away capture time, so this
# leg has to re-capture before it can prove the positive path.
gps-fix-date modern
action toggle gps
wait 1000
action toggle gps
wait 16000
assert uart.eph_replay 0

# Same cache, same code path, current receiver clock. It replays now, so the
# refusals above are the age check and not a broken replay path.
action toggle gps
wait 1000
action toggle gps
assert-eventually-virtual 30000 uart.eph_replay 3
exit
