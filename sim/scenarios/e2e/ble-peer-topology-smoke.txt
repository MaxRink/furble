# Every virtual camera peer advertises and registers.
#
# This is a harness smoke test, not a camera behavior claim. It proves the
# simulator topology can create one peer for each family, match every
# advertisement through the production CameraList parser, and persist a saved
# camera for each one.

seed ble_peers all
seed ble_saved true
wait 1000
assert ble.peers 9
assert ble.unmatched_peers 0
assert ble.saved_cameras 9
exit
