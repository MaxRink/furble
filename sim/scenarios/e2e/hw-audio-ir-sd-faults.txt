# Audio overcurrent, IR RMT timeout and SD card faults.
#
# The fault shims are board-independent, but an IR fault needs an emitter that
# is powered: the Core row has no emitter at all (`ir.state` is `absent` there,
# pinned in hw-pmic-ip5306-core.txt), and on the StickS3 the EXT_5V rail feeds
# the IR parts, so a rail-off run reads `unpowered`. The StickC Plus drives IR
# TX on G9 from its own GPIO on an AXP192 board, so the fault path is reachable
# without a rail action.
seed hw_profile stickc-plus
wait 100
assert audio.state idle
assert ir.state idle
assert sd.state absent
action sd-present
assert sd.state mounted
action audio-overcurrent
assert audio.state overcurrent
assert audio.overcurrents 1
action ir-timeout
assert ir.state timeout
assert ir.timeouts 1
action sd-error
assert sd.state error
assert sd.errors 1
assert ui.page main
exit
