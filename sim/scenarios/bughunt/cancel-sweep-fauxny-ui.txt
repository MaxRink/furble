# Cancel sweep: FauxNY test camera, UI connect button
#
# Plan 172. One cancel per (offset, pass): each lands at a fixed virtual-time
# offset across the connect window, and after every one of them the same settle
# invariant runs. The drain must empty inside DISCONNECT_DRAIN_RECLAIM_MS, no
# connect may be left in flight, and Control must be back at idle. The file ends
# by proving the connect gate reopened, because a wedge presents as a session
# that never comes back rather than as a bad state at the instant of the cancel.
#
# FauxNY has no radio and its connect is a 2500 ms wait that does poll the
# cancel token, so this leg is the control case: every cancel here is
# expected to unwind inside one 25 ms slice. It is in the sweep so that a
# regression breaking the plan 148 polling contract fails on the topology
# where the contract is currently honoured, not only on the ones where it
# is not.
#
# Offsets 10, 150, 400, 900, 1800, 2600, 3400 ms, two passes each.
seed fauxny true
seed reconnect true
wait 300
assert control.state idle

# offset 10 ms, pass 1
action connect
wait 10
action cancel
assert-eventually-virtual 6000 control.zombies 0
