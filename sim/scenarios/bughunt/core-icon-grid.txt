# The icon grids on the 320x240 panel: the home menu and the Settings page.
#
# Both pages lay their entries out as a grid of icons with the entry name under
# the icon. Three defects lived here and none of them was visible to a fit
# query, because all three kept the page inside the viewport:
#
#  - The Settings page carried fourteen entries and the grid held twelve cells,
#    so two pairs shared a cell and drew through each other.
#  - The name under an icon scrolled. A scrolling label runs a permanent
#    animation that invalidates its cell on every frame, which is the redraw
#    trap the project guide names, and at any instant it shows only part of the
#    name: on the 320x240 panel "Features" read "atures".
#  - The rows were a fixed fraction of the page, so a name that needed two lines
#    had its second line clipped away below the icon.
#
# The three asserts below are the teeth for those three. "cut_labels" is how
# many labels cannot draw all of their own text, "label_overlaps" is how many
# pairs of widgets are drawn over each other, and walking into a page and back
# proves the entries still route.
#
# core-icon-grid-large.txt is the same walk at the maximum text size, where the
# names wrap and both pages scroll. Two files because the text size is a boot
# seed, following home-seven-rows.txt and home-seven-rows-large.txt.
seed fauxny true
seed gps true
seed imu true
wait 400

# Home menu.
assert ui.page main
assert ui.cut_labels 0
assert ui.label_overlaps 0
# At the default size the home menu still fits the page.
assert ui.overflow no

# Settings page.
action page settings
wait 250
assert ui.page settings
assert ui.cut_labels 0
assert ui.label_overlaps 0
# The page opens at its top whether it scrolls or not.
assert ui.scroll_top 0

# Every entry in the second and third row routes. On master the two pairs that
# shared a cell drew over each other and only one of each pair could be reached.
action nav theme
wait 150
assert ui.page theme
action page settings
wait 150
action nav timer
wait 150
assert ui.page timer
action page settings
wait 150
action nav feedback
wait 150
assert ui.page feedback
action page settings
wait 150
assert ui.page settings
assert ui.label_overlaps 0
exit
