# The Connected page at the maximum text size, on the 135x240 panel, in the
# physical-button layout that board ships.
#
# stick-notouch-layout-135.txt walks the same layout at the default size. This
# file exists for one measurement the default size cannot make.
#
# The Connected page carries eight rows in a 167 px sub page, so at the Large
# face it does not fit and the page scrolls. That is the intended behaviour: a
# page honours the size the user chose and scrolls rather than shrinking the
# face. What has to hold instead is that nothing is drawn over anything else and
# that the scroll is bounded, which is what this file pins.
#
# It matters more here than on other pages because addMainMenu's page dispatch
# hides and disables the header back button on the Connected page. It is the
# root for the whole session, so a Disconnect below the fold is only reachable
# by scrolling the encoder through seven rows.
#
# Every seed is deliberate. no_touch selects the shipped layout, text_size 2
# selects the maximum face, and imu and ir bring the Level and Infrared entries
# on so all eight rows are present: with either off the page carries fewer rows
# and the overflow this file guards does not appear.
# See plans/168-notouch-layout-overflows.md.
seed no_touch true
seed text_size 2
seed fauxny true
seed saved_camera true
seed gps true
seed imu true
wait 300
assert ui.nav_layout buttons
assert setting.text_size 2

# The Infrared entry appears once the IR switch is on.
action nav infrared
wait 150
action toggle ir
wait 150
home
wait 250
assert ui.page main

# Eight rows, all on the page, at the largest face this board offers.
action connect
wait 3200
assert ui.page connected
assert ui.connected yes
# This page scrolls at this size by design. A page honours the text size the
# user chose and scrolls when the rows stop fitting; it does not shrink the
# face to fake a fit. What still has to hold is that nothing is drawn over
# anything else, so the fit assert is replaced by the two that matter.
assert ui.label_overlaps 0
# The page opens at its top, scrolled or not.
assert ui.scroll_top 0
assert ui.indicator_clearance clear
# Eight entries, each a container with its icon and its label, plus the page.
assert ui.visible_objects 25
exit
