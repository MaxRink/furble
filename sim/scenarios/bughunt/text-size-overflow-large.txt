# Content-overflow regression for the global Large text size (text_size 2).
#
# Companion to overflow-sweep.txt, which only exercises the default Normal font.
# The Text size setting scales the LVGL theme font, so a larger font can push a
# once-fitting page past the viewport. This scenario seeds Large, then walks the
# same pages overflow-sweep walks, so the compact pages that must always fit are
# layout-verified at the largest font, not just at Normal. Run it on the same
# panels overflow-sweep runs on: the 80x160 M5StickC and the 135x240 boards.
# Large lifts the theme font 12 -> 14 on the 80x160 StickC and 16 -> 22 on the
# 135x240 boards.
#
# The compact pages carry an "assert ui.overflow no": the home menu, the Display
# page, the Timer settings list, the Remote shutter page and the Connected page.
# The long settings lists (features, gps, bluetooth, about, power, diagnostics)
# hold more rows than a short panel can show, so they scroll by design and only
# print their overflow state.
seed text_size 2
seed fauxny true
seed gps true
# The IMU is deliberately not seeded here. Seeding it adds the Level row to
# the Connected page as well as the home page, and on the 80x160 panel the
# Connected page then scrolls at this size (13 px, a pre-existing gap noted
# in plan 153), which would fail the Connected page assert below for a reason
# unrelated to the text size. The Level row's home fit at Large is guarded by
# home-seven-rows-large.txt on every panel instead.
wait 300
# The seeded Large size was loaded on boot.
assert setting.text_size 2
# Home menu: must fit on the narrow panels.
assert ui.page main
assert ui.overflow no
action page settings
wait 100
print ui.page
print ui.overflow
action nav display
wait 100
# Display page: short, must fit on the narrow panels.
assert ui.page display
assert ui.overflow no
action page settings
action nav features
wait 100
print ui.page
print ui.overflow
action page settings
action nav gps
wait 100
print ui.page
print ui.overflow
action page settings
action nav timer
wait 100
# Timer settings list (Count, Delay, Shutter, Wait): must fit on the narrow panels.
assert ui.page timer
assert ui.overflow no
action page settings
action nav bluetooth
wait 100
print ui.page
print ui.overflow
action page settings
action nav about
wait 100
print ui.page
print ui.overflow
action page settings
action nav power
wait 100
print ui.page
print ui.overflow
action page settings
action nav diagnostics
wait 100
print ui.page
print ui.overflow
# Remote shutter page: compact, must fit on the narrow panels.
action blind
wait 200
assert ui.page shutter
assert ui.overflow no
# Connected page: compact, must fit on the narrow panels.
action connect
wait 3200
assert ui.connected yes
assert ui.page connected
assert ui.overflow no
exit
