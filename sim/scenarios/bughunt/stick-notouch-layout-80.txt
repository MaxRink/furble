# Layout audit for the physical-button layout the M5StickC ships, on the
# 80x160 panel.
#
# UI::begin() picks the navigation layout at runtime from M5.Touch.isEnabled().
# The Stick boards have no touch panel,
# so this is the layout it always renders: a navigation bar band reserved at the
# bottom of the window content, ICON_HEADER_SIZE + 2 = 26 px tall, plus the
# three button legends. On the Stick boards the bar stays empty and the
# legends float against the screen edges instead.
#
# Where the Right one lands is the LEGEND setting, and this file measures the
# default, Buttons: at LV_ALIGN_RIGHT_MID with no offset, a 24 px square at y 68
# to 91, halfway down the panel, drawn over
# the page. `reserveLegendColumns()` keeps that column clear, which is what the
# clearance assertions below prove.
# legend-bottom-80.txt walks the same pages with the other value, where all
# three legends are in the band and no page gives up any width.
#
# The M5GFX SDL panel always attaches a mouse-driven touch device, so every
# other scenario measures the touch layout, which is 26 px taller. This one
# seeds "no_touch true" to detach that device. One file per board on purpose:
# the expectations below are geometry, and a shared file would have to soften
# every line to the weakest board.
#
# The first assertion is a hard guard. Without it a run that lost the seed would
# fall back to the touch layout and pass for the wrong reason, which is the
# exact failure this scenario exists to remove.
#
# Indicator and overlap regressions below are hard assertions. The Sensors fit
# remains an explicit xassert for its documented 7 px vertical overflow; that
# page scrolls rather than shrinking the selected text size. See
# plans/165-sim-no-touch-layout.md and plans/168-notouch-layout-overflows.md.
seed no_touch true
seed fauxny true
seed saved_camera true
seed gps true
seed imu true
wait 300

assert ui.legend_visible yes

# This page scrolls at this size by design. A page honours the text size the
# user chose and scrolls when the rows stop fitting; it does not shrink the
# face to fake a fit. What still has to hold is that nothing is drawn over
# anything else.
assert ui.label_overlaps 0
assert ui.indicator_clearance clear
