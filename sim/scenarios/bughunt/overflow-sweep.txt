# Report content-overflow (content taller than viewport) for every reachable
# page. Run against each panel class to surface layout overflow, worst on 80x160.
#
# Some pages are compact and must always fit the panel: the home menu, the
# display page and the timer settings list. Those carry an "assert ui.overflow
# no" so this scenario is a regression test. It fails on the pre-fix firmware,
# where the home menu and timer page overflow at 80x160 (M5StickC), and passes
# once the narrow-panel layout fits at 80x160, 135x240 and 320x240.
#
# The long settings lists (features, gps, bluetooth, about and the diagnostics
# sub-pages) hold more rows than a short panel can show, so they scroll by
# design. Those pages only print their overflow state, they are not asserted.
seed fauxny true
seed gps true
wait 300
# Home menu: must fit on every panel.
print ui.page
print ui.overflow
assert ui.overflow no
action page settings
wait 100
# Display page: short, must fit on every panel.
print ui.page
print ui.overflow
action nav display
wait 100
print ui.page
print ui.overflow
assert ui.overflow no
action page settings
action nav features
wait 100
# Features carries the Button Mode roller plus its static one-button gesture
# hint. This long list scrolls by design on every panel, so its overflow is
# printed, not asserted. The compact must-fit pages above (home, display) and
# below (timer) keep their "assert ui.overflow no", so this sweep still catches
# any regression where the hint leaks overflow into a page that must fit.
print ui.page
print ui.overflow
action page settings
action nav gps
wait 100
print ui.page
print ui.overflow
action page settings
action nav timer
wait 100
# Timer settings list (Count, Delay, Shutter, Wait): must fit on every panel.
print ui.page
print ui.overflow
assert ui.overflow no
action page settings
action nav bluetooth
wait 100
print ui.page
print ui.overflow
action page settings
action nav about
wait 100
print ui.page
print ui.overflow
action page settings
action nav power
wait 100
print ui.page
print ui.overflow
action page settings
action nav diagnostics
wait 100
print ui.page
print ui.overflow
action nav device_info
wait 100
print ui.page
print ui.overflow
action page diagnostics
action nav power_state
wait 100
print ui.page
print ui.overflow
action page diagnostics
action nav ble
wait 100
print ui.page
print ui.overflow
action page diagnostics
action nav battery
wait 100
print ui.page
print ui.overflow
# Spirit level page (PR #28 v3.1): one top readout row split roll left, pitch
# right, then the bullseye and centre target ring centred below. A compact fixed
# layout that must fit every panel with no overlap or scroll.
home
wait 100
action nav level
wait 150
print ui.page
print ui.overflow
assert ui.overflow no
exit
