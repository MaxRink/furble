# A resume record whose wake time is two hours old, read on a timed wake.
#
# The StickS3 has no RTC chip and an NVS-restored clock does not advance across
# power-off, so trustedWallClock() is false at boot and the record's wake time
# cannot be compared with now. The M5PM1 timer is then the authority: the
# resume waits RESUME_WAKE_MARGIN_S (15 s) from boot, because the alarm fires
# that long before the shot, and then takes the next shot. Telling an early,
# late or stale record apart needs a battery-backed RTC at boot, which the
# simulator does not model yet.
seed fauxny true
seed autoconnect true
seed ivl_sleep true
seed timed_wake true
seed resume_fixture stale
seed interval_count 2
seed interval_delay 1
seed interval_shutter 30
wait 5000
assert platform.wake_marker no
assert camera.shutter_presses 0
assert ui.interval_state shutter
assert-eventually-virtual 20000 ui.interval_state finished
assert camera.shutter_presses 1
exit
