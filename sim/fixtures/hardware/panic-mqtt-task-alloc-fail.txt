# MQTT owner-task allocation failure. Expected: SIM PANIC, exit 3.
#
# The pre-#392 MQTT boot loop on the StickS3 was an allocation failure inside
# esp_mqtt_client_start -> xTaskCreate at 0x1800. With the heap abort policy a
# failed task allocation aborts the device; the firmware's `!= pdPASS` branch
# is unreachable on hardware. This fixture fails the owner task deliberately
# and proves the simulator aborts the same way.
#
# Requires the native MQTT simulator build: FURBLE_SIM_MQTT=1.
seed wifi_connected true
seed task_create_fail mqtt
wait 100
exit
