# Espressif32 6.13.0 and ESP-IDF 5.5.3

## Scope

This slice updates the firmware build platform from Espressif32 6.12.0 to
6.13.0 and the explicit ESP-IDF framework package from 3.50402.0 (ESP-IDF
5.4.2) to 3.50503.0 (ESP-IDF 5.5.3). The M5PM1, M5GFX, M5Unified,
TinyGPSPlus, NimBLE, and LVGL pins remain unchanged from plan 129.

The exact inputs are recorded in `platformio.ini` and
`tools/reproducible-build.lock`. All firmware environments retain the same
extra scripts, including the NimBLE patch and reproducible-build guard.

## Compatibility

The five release boards, the S3 headless environment, and all five debug
variants use the upgraded framework. No application compatibility shim was
needed. ESP-IDF 5.5.3 emits existing Furble initializer warnings and its
existing Kconfig boolean-default notes. The M5Unified touch helper compiles
with the updated touch driver and no `touch_pad_t` error.

PlatformIO normalizes `/private/tmp` to `/tmp` on macOS. Builds must use the
canonical path so the Espressif32 builder keeps component object paths unique.
This is a host invocation detail and does not change project inputs.

## Verification gate

Run with `FURBLE_VERSION=dev FURBLE_TEST=0`:

1. Build all five release environments, `esp32-s3-headless`, and all five
   debug environments.
2. Run host protocol and camera checks, simulator build and smoke checks,
   partition checks, and the reproducible-input guard.
3. Record firmware sizes and warnings. Hardware flashing and camera testing
   remain separate gates. No hardware claim is made by this dependency slice.

## Rollback

Restore `platformio.ini` and `tools/reproducible-build.lock` to the 6.12.0 /
3.50402.0 pair, and restore the six checked-in board `sdkconfig` files to the
versions generated by that toolchain. No application source migration is
required.
