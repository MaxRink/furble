# furble documentation

Every page in this directory, grouped by what a reader is trying to do. The
reference pages are written from the source and cite `file:line`, so a claim can
be checked against the code that implements it.

Start at the top level [README](../README.md) for the product overview, or
[CONTRIBUTING](../CONTRIBUTING.md) for the build and gate workflow.

## Keeping this index true

A new page under `docs/` belongs in this index in the same pull request. The
per-directory `README.md` files are the indexes for `components/`, `protocols/`,
`power/`, `camera-research/` and `wiki/`, and each of those is linked from here.
