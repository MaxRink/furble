# Texas Instruments BQ25896

**Part and package.** TI BQ25896, an I2C controlled single-cell switch-mode
charger with power path and OTG boost. Package and pinout were not read and are
UNVERIFIED.

**Role in furble.** None yet. The T-LoRa Pager carries it, and the plan records
why no driver exists: the BQ27220 current sign already tells furble whether the
pack is charging or discharging, so the charger is left to its power-on defaults
(`plans/322-hardware-abstraction.md`, phase 1 audit, BQ25896 row).

**Documents.** [BQ25896-DS]
