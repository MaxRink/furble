# Sitronix ST7789 and ST7789V2

**Part and package.** Sitronix ST7789V and ST7789V2, TFT controller and driver
chips with frame memory, COG bumped die. The panel module varies by board; the
glass, flex and package for a given board were not read and are UNVERIFIED.

**Status.** board support. M5GFX drives the panel on `m5stick-c-plus`,
`m5stick-c-plus2` and `m5stick-s3`; furble never issues a panel command itself.

**Role in furble.** The panel on the StickS3 and most M5 boards. The pinned board
support library drives it, so furble never issues a panel command itself. What it
owns is the sleep timing around the library calls
(`src/FurbleUI.cpp:1888` to `:1900`).

**Documents.** [ST7789V-DS], [ST7789V2-DS]

## The sleep timing rule

The rule is one way, and the tree states it backwards in three places.

- Correct: after Sleep Out (11h) wait 120 ms before the next Sleep In (10h), and
  wait 5 ms after Sleep Out before any other command. Source: ST7796S-DS section
  9.2.12 and section 9.2.13, reported by the verification pass, with the same
  rule in the ST7789 and ILI934x families.
- Wrong as written: `include/FurbleUI.h:1135` says "ST7789 and ILI934x need 120
  ms between Sleep In and Sleep Out", `plans/implemented/322-hardware-abstraction.md:75`
  says "waits the 120 ms SLPIN/SLPOUT dwell", and `:173` says "wait 120 ms
  between SLPIN and SLPOUT".
- What the code does: `src/FurbleUI.cpp:1888` to `:1892` measures the time since
  Sleep In and delays the Sleep Out. That is the opposite direction, so the
  window the documents require, 120 ms after Sleep Out before the next Sleep In,
  is not enforced at all.
- The 5 ms post Sleep Out window is not enforced either.
- This is recorded as a documentation and timing defect. No firmware change is
  made here.

## Where the code implements it

- `src/FurbleUI.cpp:1860` to `:1863`: waits for the DMA queue, then Sleep In.
- `src/FurbleUI.cpp:1888` to `:1897`: the dwell, the APB lock reacquire and
  Sleep Out.
- `include/FurbleUI.h:1136`: `DISPLAY_SLEEP_DWELL_MS = 120`.
- `src/FurbleUI.cpp:1843`: the same dwell guards a sleep that follows a recent
  wake.
