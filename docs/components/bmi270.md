# Bosch BMI270

**Part and package.** Bosch Sensortec BMI270, a six-axis inertial measurement unit
with an integrated feature engine. Package and pinout were not read and are
UNVERIFIED.

**Role in furble.** The IMU and any-motion source on the StickS3. furble uses the
feature engine for any-motion and no-motion instead of polling, so the IMU stays
in a low power state between events (`src/FurbleIMUMotionBMI270.cpp:17` to `:80`).

**Documents.** [BMI270-DS], [BMI270-API]

### Section corrections from the verification pass

The verification passes read revision 1.6 and found ten errors in the numbers
the page carried: nine section numbers and one register address, all inherited
from the source comments.

| Register | Section in the source comment | Correct section | State |
| :--- | :--- | :--- | :--- |
| INT_STATUS_0 0x1C | 5.2.9 | 5.2.28 | REPORTED |
| INTERNAL_STATUS 0x21 | 5.2.14 | 5.2.33 | REPORTED |
| FEAT_PAGE 0x2F | 5.2.24 | 5.2.39 | REPORTED |
| FEATURES 0x30 | 5.2.24 | 5.2.40 | REPORTED |
| INT1_IO_CTRL 0x53 | 5.2.36 | 5.2.58 | REPORTED |
| INT_LATCH 0x55 | 5.2.38 | 5.2.60 | REPORTED |
| INT1_MAP_FEAT 0x56 | 5.2.39 | 5.2.61 | REPORTED |
| INT_MAP_DATA 0x58 | 5.2.40 | 5.2.63 | REPORTED |
| PWR_CONF 0x7C | 5.2.44 | 5.2.84 | REPORTED |
| Internal status 0x21 | register address given as 0x2E here | 0x2E was a page error; the source has 0x21 at `src/FurbleIMUMotionBMI270.cpp:31` | VERIFIED |

The comments for INT_STATUS_0, INTERNAL_STATUS, FEAT_PAGE, FEATURES,
INT1_MAP_FEAT and INT_MAP_DATA are corrected in this change. Four source
comments are still open: `src/FurbleIMUMotionBMI270.cpp:39`, `:45` and `:62`
carry the old numbers, and `:72` names section 5.2.45 for PWR_CTRL, a section
this page cannot confirm and does not name. Correcting those is a firmware
comment change and is left to the follow-up in plan 333.
