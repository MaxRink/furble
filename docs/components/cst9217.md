# Hynitron CST9217

**Part and package.** Hynitron CST9217, a self-capacitive touch controller in
the CST92xx family. Package and pad layout were not read and are UNVERIFIED.

**Role in furble.** Planned, not driven. The T-Watch Ultra profile needs a touch
driver, and the pinned board support library has no CST9217 support, so the plan
calls for a new touch class (`plans/322-hardware-abstraction.md`, phase 1 audit
and `plans/287-mcu-portability-and-bundle-hardware.md`).

**Documents.** None confirmed.
