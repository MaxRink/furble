# Sino Wealth SH1106

**Part and package.** Sino Wealth SH1106, a 132 x 64 dot matrix OLED and PLED
segment and common driver with an on-chip controller. Package and pad layout
were not read and are UNVERIFIED.

**Role in furble.** Planned, not driven. The T-Beam Supreme profile uses a
128 x 64 SH1106 panel on I2C, and furble has no 1-bit 128 x 64 UI tier yet
(`plans/implemented/322-hardware-abstraction.md`, phase 1 audit and the profile table).

**Status.** future. No code drives it; the T-Beam Supreme profile is the board that would.

**Documents.** None confirmed.
