# Sitronix ST7735S

**Part and package.** Sitronix ST7735S, a TFT controller and driver chip with
frame memory, COG bumped die. The panel module is board specific and was not read,
so it is UNVERIFIED.

**Role in furble.** A panel the board support library drives on the 80 x 160
StickC layouts. furble does not issue panel commands. This page exists because the
power model uses the ST7735S current figures and because the panel sleep trap
covers every panel family in the tree.

**Documents.** [ST7735S-DS]

## Where the code implements it

None directly. The board support library selects and drives the panel, and the
sleep dwell in `src/FurbleUI.cpp:1888` to `:1892` applies to whatever panel the
board carries.
