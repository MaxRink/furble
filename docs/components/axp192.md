# X-Powers AXP192

**Part and package.** X-Powers AXP192, a single-cell Li-battery PMIC with an ADC
bank. Package and pinout were not read and are UNVERIFIED.

**Role in furble.** The PMIC on the M5Stack Core2 and the StickC family. The
pinned board support library drives it, so furble only writes two registers
directly: the ADC enable pair, to switch off the channels M5Unified turns on and
never reads.

**Documents.** [AXP192-DS]

## Where the code implements it

- `src/FurblePlatform.cpp:109` to `:115`: the ADC trim, guarded so it only runs
  when the detected PMIC really is an AXP192.
- `include/FurblePlatformPolicy.h:37` to `:38`: the two enable values.
- `src/FurbleBoard.cpp:21`: the rail notes that name EXTEN.

## Facts still unverified

- The REG 82H and 83H bit assignments behind 0xCC and 0x00. The values are
  CITED from the firmware, and a wrong bit leaves an ADC channel on, which costs
  current but does not break behaviour.

- The ADC sample rate register and its default.
