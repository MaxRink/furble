# QST QMI8658

**Part and package.** QST Corporation QMI8658A, a six-axis inertial measurement
unit with a motion co-processor. Package and pinout were not read and are
UNVERIFIED.

**Role in furble.** Planned, not driven. The T-Watch Ultra carries a QMI8658 on
SPI, and the plan records that furble has no motion backend for it, so the board
would ship without motion wake (`plans/322-hardware-abstraction.md` profile
table and the T-Watch Ultra note). The T-Beam Supreme carries one too
(`plans/88-alternate-hardware.md`).

**Documents.** None confirmed.
