# QST QMI8658

**Part and package.** QST Corporation QMI8658A, a low noise wide bandwidth 6D
inertial measurement unit with a motion co-processor. Package and pinout were not
read and are UNVERIFIED.

**Role in furble.** Planned, not driven. The T-Watch Ultra carries a QMI8658 on
SPI, and the plan records that furble has no motion backend for it, so the board
would ship without motion wake (`plans/implemented/322-hardware-abstraction.md` profile
table and the T-Watch Ultra note). The T-Beam Supreme carries one too
(`plans/88-alternate-hardware.md`).

**Status.** future. No code drives it. The T-Beam Supreme image compiles the IMU path out of its board row (no backend, no motion wake) and leaves the part on the ALDO1 sensor rail; the T-Watch Ultra is the other board that would need a driver.

Row 8 answers the question that kept this page open. The part does the detection
in hardware, so a future backend can arm an engine and sleep, the way the BMI270
backend does on the StickS3, rather than sampling the accelerometer to decide
whether the board moved.
