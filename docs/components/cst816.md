# Hynitron CST816

**Part and package.** Hynitron CST816, a self-capacitive touch chip. The
CST816D variant was the copy read for this page. Package and pad layout were not
read and are UNVERIFIED.

**Role in furble.** Not driven directly. The pinned board support library already
supports the CST816S, so a board that carries one needs no `lib/hal` driver
(`plans/implemented/322-hardware-abstraction.md`, phase 1 audit, which lists CST816S among the
touch classes the library has).

**Status.** board support. M5GFX drives the CST816 family, and furble holds no register table for it.

**Documents.** [CST816D-DS]
