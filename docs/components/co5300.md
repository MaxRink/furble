# CHIPONE CO5300

**Part and package.** CHIPONE Technology CO5300, an OLED smart watch display
driver IC with an AMOLED driver stage. Package and pad layout were not read and
are UNVERIFIED.

**Role in furble.** Driven, through the board support library's panel class
rather than a register driver of our own. The T-Watch Ultra's 2.06 inch 502x410
AMOLED is on quad SPI `[S13, S14]`, and `lgfx::Panel_CO5300` in the pinned M5GFX
0.2.27 already carries that exact geometry and init sequence, so furble supplies
wiring, the column offset and brightness (`src/FurbleDisplay.cpp`).

**Status.** community. The panel path is implemented and simulated; it has not
been run on a T-Watch Ultra. Brightness is the controller's own 0x51 command, so
there is no backlight pin and no APB clock lock.

**Documents.** [CO5300-DS]

## Where the code implements it

`src/FurbleDisplay.cpp` builds the panel and bus; `src/FurbleLilyGo.cpp` carries
the wiring, geometry and offset; `src/FurbleLilyGoDevice.cpp` brings up the
AXP2101 rails and the XL9555 panel-supply enable that the panel needs before it
answers.
