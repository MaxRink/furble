# CHIPONE CO5300

**Part and package.** CHIPONE Technology CO5300, an OLED smart watch display
driver IC with an AMOLED driver stage. Package and pad layout were not read and
are UNVERIFIED.

**Role in furble.** Planned, not driven. The T-Watch Ultra profile uses a CO5300
AMOLED on quad SPI (`plans/322-hardware-abstraction.md`, profile table). The
pinned board support library already has a panel class for it, so furble needs a
profile and a brightness path, not a register driver.

**Documents.** [CO5300-DS]
