# Texas Instruments TCA8418

**Part and package.** TI TCA8418, a keypad scan IC with up to 10 columns by 8
rows, 80 keys, with ESD protection. Package and pinout were not read and are
UNVERIFIED.

**Role in furble.** Planned, not driven. The Cardputer Adv and the T-LoRa Pager
have keyboards, and the pinned board support library has no TCA8418 support, so
the plan expects a new driver (`plans/322-hardware-abstraction.md`, phase 1
audit, TCA8418 row).

**Documents.** [TCA8418-DS]
