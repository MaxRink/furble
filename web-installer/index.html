furble web installer

A Bluetooth wireless remote shutter release/button for Fujifilm X/GFX, Canon EOS, Nikon and Sony cameras.

Flash furble firmware to a supported M5Stack device.

Select your device:

The debug build is larger and enables the developer serial console. Use it to capture diagnostics for bug reports.

Capture BT debug dump

Attach a Bluetooth diagnostic dump to a camera bug report. This needs a debug build flashed first: tick the "Debug build" box above and install it, then come back here.

Flashing and this capture cannot use the serial port at the same time. Finish the install first, close its dialog, then click Connect below.

This browser does not support Web Serial. Use a Chromium based browser such as Chrome or Edge on a desktop to capture a dump.

Recommended order: Connect, Start recording, reproduce the problem on the device, Stop and dump journal. Run a scan and an explore too if the bug is about finding or pairing a camera.
